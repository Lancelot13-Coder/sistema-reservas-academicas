# Propuesta: Sistema inicial de reservas académicas

## Problema
La gestión manual de espacios académicos dificulta la consulta de disponibilidad, seguimiento y control de solicitudes.

## Alcance
Implementar autenticación, catálogo de espacios, solicitudes, estados, revisión por gestores, cancelación, historial y prevención de solapamientos.

## Fuera de alcance de esta fase
El límite de cuatro horas consecutivas se reserva para una solicitud de cambio formal posterior.

## Criterios de éxito
Usuarios autenticados pueden solicitar y consultar sus reservas; gestores pueden revisar solicitudes; el sistema bloquea conflictos horarios y aplica control de acceso.
